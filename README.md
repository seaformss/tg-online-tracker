# Telegram Online Tracker

Показывает, когда выбранные пользователи Telegram выходят в сеть и уходят из неё.
Каждая смена статуса печатается в консоль и пишется в `online_log.csv`.

## Запуск

1. Распакуйте архив в любую папку.
2. Дважды кликните `start.bat` (macOS/Linux: `./start.sh`).
   Если Python не установлен, скрипт попробует поставить его сам.
3. При первом запуске введите:
   - `api_id` и `api_hash` (получить на https://my.telegram.org/apps),
   - юзернеймы через запятую,
   - затем номер телефона и код из Telegram (вход в ваш аккаунт).

Дальше всё запускается одним кликом на `start.bat`.

## Файлы, которые появятся

- `config.json` - ваши ключи и список юзернеймов. Можно править руками
  (там же `interval` - пауза между проверками в секундах, минимум 10,
  и `pairs` - пары вида `[["user1", "user2"]]` для сообщения «оба в сети»).
- `tracker.session` - вход в ваш Telegram-аккаунт. **Никому не отдавайте**
  этот файл и `config.json`.
- `online_log.csv` - журнал смен статуса (открывается в Excel).

Чтобы настроить заново, удалите `config.json`. Чтобы выйти из аккаунта, удалите `tracker.session`.

## Важно

- Слишком частые проверки приводят к временному ограничению от Telegram (до 24 часов),
  поэтому интервал не меньше 10 секунд, лучше 20-30.
- Если человек скрыл время последнего визита, Telegram показывает только
  «недавно», и точный онлайн увидеть нельзя. Скрипт пишет «статус скрыт».
- Скрипт использует официальный API Telegram. Следите за людьми только
  в рамках разумного и с учётом их приватности.
